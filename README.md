## 🎯 Басты Мақсат (Mission)
1. **Елге пайда тигізу:** IT саласын күрделі терминдерсіз, қарапайым қазақ тілінде түсіндіру.
2. **Сенімді жеке бренд (Trust):** 1 ай ішінде 12–15 сапалы Reels жариялап, халықтың шынайы сеніміне кіру.
3. **Аудитория базасы:** Telegram каналға алғашқы 200–500 белсенді, сауатты IT-ге қызығушы оқырман жинау.
4. **Курсқа дайындық:** Нақты аудиторияның сұранысын (CustDev) анықтап, болашақ курстың алғашқы ағымына негіз қалау.

## ⚖️ «Қамшы» және Өз-өзіммен Келісім-шарт (Commitment)
* **Челлендж уақыты:** 2026 жылғы Қыркүйек (30 күн).
* **Жариялау жиілігі:** Аптасына 3 Reels (Дүйсенбі / Сәрсенбі / Жұма).
* **Басты қағида:** ⛓️ *«Тізбекті үзбеу» (Don't break the chain)*. Күн сайын осы репозиторийге өзгеріс (commit) енгізіледі.
* **Жаза (Loss Aversion):** Егер аптасына 3 видеоны уақытында жарияламасам, бақылаушыма/досыма **10 000 ₸** айыппұл төлеймін немесе оқырмандар арасында ойнатамын.
